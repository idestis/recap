Capture

Start from the terminal or from anywhere

We do plenty of things by hand: reset a local database, onboard a service, rotate a cert, cut a release, chase an incident. While you do it, recap keeps the commands, your decisions and the links you opened. Incidents are one example, not the whole point.

  • Terminal. recap start is instant and offline. Open another tab and run recap join.
  • Anywhere. Press ⌥⇧Space in any app to start a session or add context.
  • Type or dictate. Use macOS Dictation or Wispr Flow in the overlay. recap never records audio.

Review

Stop, keep what mattered

When you are done, recap shows everything it captured as a checklist. Failed commands start unticked. You tick what belongs, say whether it fixed the problem, and choose whether to open a pull request.

  • One fixed question: did this fix it?
  • Related, maybe and excluded commands are separated for you.
  • Scripts and agents get the same flow with --fixed and --json.

Recipes

A recipe your team can trust

The draft is plain Markdown in your own Git repo. Values become variables, risk is labeled, undo steps sit next to the step they reverse, and every recipe carries how often it ran and where it was last verified.

recipes/fix-checkout-api-502s.md

Fix Checkout API 502s

idfix-checkout-api-502s
riskrisky-prod
tools[kubectl]
trust{ runs: 1, ok: 1 }
verified[prod-eu 2026-10-27]
vars[context, deployment, namespace, pod]

Situation

Checkout API returning 502s. Rollback not an option as migration 0142 has already run.

Preconditions

  • rollback ruled out, migration 0142 already ran

Steps

  1. Switch kube context safe 
    kubectx {context}
  2. List pods in namespace safe 
    kubectl get pods -n {namespace}
  3. Describe pod safe 
    kubectl describe pod {pod} -n {namespace}
  4. Adjust deployment resource limits risky · prod 
    kubectl set resources deploy/{deployment} -n {namespace} --limits=memory=1Gi

    Undo: kubectl rollout undo deploy/{deployment} -n {namespace}

Two more safe steps trimmed here: resource usage and rollout status.

Run

Next time, one command

Search by symptom. recap shows the preflight, asks once for each value, and fills it into every step. Safe steps run straight through. Risky ones stop and ask first.

  • Preview is the default; --execute runs the steps.
  • Pass values with --var name=value for scripts.
  • Find recipes by meaning with recap find.

Agents

Teach Claude Code what you already know

Any recipe can become a Claude Code skill. The skill does not paste commands for the agent to improvise. It calls recap run, so the same preflight and risk gates apply.

  • Capture. With recap hooks install, the commands Claude Code runs land in the same timeline as yours.
  • Guardrail. When a verified recipe exists, hooks block destructive prod commands that bypass it.

Spaces and models

One install, every team

Spaces. Each space is a recipe repo. A team space publishes by pull request, a personal one pushes. recap picks the space from the folder you are in.

Models. Use Ollama on your machine or any OpenAI-compatible API. The key lives in the Keychain, never in a config file.

Privacy

Your work stays yours

recap does

  • Mask secrets locally before any model call or Git write
  • Keep raw timelines on your Mac
  • Store API keys in the Keychain
  • Ask before risky steps
  • Publish only what you reviewed

recap doesn't

  • Send telemetry or run a hosted service
  • Record audio
  • Delete anything on its own
  • Let a model change a command or lower a risk label
  • Put timelines, screenshots or transcripts in Git

Get started

Four steps to your first recipe

  1. 1. Install from source

    $ git clone https://github.com/idestis/recap && cd recap && task pkg
# then open dist/Recap-*.pkg

  2. 2. Add shell integration

    $ recap shell-init --install
✓ Added to ~/.zshrc eval "$(recap shell-init zsh)"
  Open a new tab or run exec zsh to load it.

  3. 3. Make a recipe repo your space

    $ cd ~/runbooks && recap init

  4. 4. Start recording

    $ recap start "checkout API returning 502s"
