Fix OOMKilled pods

risky · prod

Preconditions

  • kubectl context points at the right cluster
  • Deployment is not mid-rollout

Steps

  1. List pods and confirm the OOMKilled status
    kubectl -n {namespace} get pods
  2. Raise the memory limit
    kubectl -n {namespace} set resources deploy/{deployment} --limits=memory=1Gi
  3. Watch the rollout
    kubectl -n {namespace} rollout status deploy/{deployment}
  4. Confirm pods are Ready
    kubectl -n {namespace} get pods

Undo: kubectl -n {namespace} rollout undo deploy/{deployment}

How it works

Five steps from raw terminal noise to a recipe your team can trust.

  1. CaptureCommands from attached tabs, Claude Code tool calls, notes, links and files.
  2. RedactSecrets are masked on your Mac before any model call or Git write.
  3. Label riskRules mark each step safe, risky or destructive, and flag prod.
  4. DraftTemplates, or your own model. Models reword; commands never change.
  5. Review & publishPick what to keep, dedup into variants, then open a PR or push.

Built for the next 3 a.m.

Small, local, and honest about risk.

Recipes in your Git repo

Plain, deterministic Markdown with preconditions, numbered steps and an undo line. Reviewable diffs, no lock-in.

Spaces for every team

One install, many recipe repos, picked by the folder you work in. Each publishes by pull request, push, or not at all.

Bring your own model

Use templates, Ollama locally, or any OpenAI-compatible API. API keys stay in the macOS Keychain.

Quick context overlay

Press ⌥⇧Space anywhere for a glass input bar. Type or dictate with macOS Dictation or Wispr Flow, and attach a screenshot or tab link.

Risk you can trust

Risk comes from rules. A model may raise it, never lower it. Risky steps ask before they run.

Works with Claude Code

Hooks record its commands and can block destructive prod commands when a verified recipe exists.

What recap does and doesn't do

No recap cloud. Raw timelines stay on your Mac; only reviewed recipes go to Git.

Does

  • Mask secrets locally before any model call or Git write
  • Keep raw timelines on your Mac
  • Store API keys in the macOS Keychain
  • Ask before risky steps
  • Publish only recipes you reviewed

Doesn't

  • Send telemetry or run a hosted service
  • Record audio, ever
  • Delete anything on its own
  • Let a model change a command or lower a risk label
  • Put timelines, screenshots or transcripts in Git
