recap docs

recap records the work you do by hand, then turns the parts you keep into a recipe. Run the recipe again with new values, or hand it to Claude Code as a skill.

Install

recap needs macOS 14 or later. It is early development software, so you build it from source for now.

git clone https://github.com/idestis/recap && cd recap && task pkg
# then open dist/Recap-*.pkg

The package installs the menu bar app and the recap command line tool. If you only want the CLI, build it with task build.

Shell setup

The shell hook is what lets recap see the commands you type and lets new tabs join a running session. Install it once:

$ recap shell-init --install
✓ Added to ~/.zshrc eval "$(recap shell-init zsh)"
  Open a new tab or run exec zsh to load it.

Check it with recap shell-init --status. Without it, recap start asks you to set it up first. To start anyway and capture notes and links only, use recap start --no-shell.

Spaces

A space is a recipe repo. Run recap init inside a folder to make that folder a space:

$ cd ~/runbooks && recap init
✓ Space runbooks → ~/runbooks
  publish: none · config: ~/recap/config.yaml

To set everything up in one command:

recap init --name team --remote git@github.com:acme/runbooks.git --publish pr --path ~/code/acme

List spaces with recap spaces and switch with recap spaces use. recap picks a space in this order, first match wins:

  1. --space flag
  2. RECAP_SPACE environment variable
  3. the folder you are in
  4. the default space

Sessions

Start a session from the terminal, or press ⌥⇧Space in any app to open the overlay. Starting is instant and works offline.

$ recap start checkout API returning 502s
● Recording  2026-10-27.1  checkout-api-returning-502s
  space runbooks
  New tab? run: recap join   ·   add context: recap ctx "…"
  • recap join attaches another tab to the active session; recap leave detaches it while recording continues elsewhere.
  • recap ctx adds anything you believe is context: a note, a link, a file, or text piped on stdin.
  • recap status shows the active session, attached tabs and sources.
  • recap timeline shows everything captured, merged by time, with secrets masked.
$ recap ctx "rollback ruled out, migration 0142 already ran https://grafana.example.com/d/checkout"
✓ Note added · decision
✓ Dashboard linked https://grafana.example.com/d/checkout

$ recap timeline
  13:14  Terminal  kubectx prod-eu
  13:14  Terminal  kubectl get pods -n checkout
  13:14  Terminal  kubectl logs checkout-api-7d9f8-x2k4p -n checkout --previus  exit 1
  13:14  Terminal  kubectl set resources deploy/checkout-api -n checkout --limits=memory=1Gi  risky · prod
  13:14  Note      rollback ruled out, migration 0142 already ran  decision
  13:14  Dashboard https://grafana.example.com/d/checkout

No guessing. recap never guesses where you are: a step's Kubernetes context is the last kubectx / kubectl config use-context you ran in the session, or --context on the command, and it becomes a {context} variable. Only the Claude Code guard reads the live kubeconfig, because it checks the command about to run.

Stop and review

In a terminal, recap stop shows a checklist titled Keep for the recipe. Failed commands start unticked. Then it asks Did this fix it? and, if the space publishes by pull request, whether to open one.

Everything the prompts ask can be answered with flags, so scripts and agents never block:

FlagEffect
--fixed / --not-fixedAnswer the fixed question.
--publishPublish after drafting.
--jsonMachine-readable output.
--no-modelDraft from templates; no model call.
 
$ recap stop --fixed
  Related    5 commands · 1 notes · 1 links/files
  Excluded   1 failed commands
✓ Draft: "Fix Checkout API 502s" · risky-prod · 6 steps
✓ Wrote sessions/2026-10-27.1-checkout-api-returning-502s/ in runbooks
  Review delta.md, then: recap apply 2026-10-27.1

Publishing

recap publish commits a session's recipe files according to the space: pr opens a pull request, push pushes, none leaves the files for you. Your checkout is never switched; pull request commits are made from a temporary worktree.

✓ Pull request https://github.com/acme/runbooks/pull/42

Apply

A stop writes a session folder with a draft and a delta.md. Review it, then merge it into your recipes:

$ recap apply checkout-api-returning-502s
✓ Added recipes/fix-checkout-api-502s.md
✓ Removed session folder (still in Git history)
  Commit when ready: git -C ~/runbooks add -A && git commit

recap apply takes the handle (2026-10-27.1) or the name. Use --keep to keep the session folder and --publish to publish right after.

Find and run

Search recipes by meaning, with trust and risk shown:

$ recap find pods out of memory
  fix-checkout-api-502s Fix Checkout API 502s              1/1 ok                 risky-prod

recap run takes a recipe name or a symptom. It prints the preflight, then asks for each missing value. Pass values yourself with --var name=value. Preview is the default; add --execute to run. Risky steps ask before they run.

$ recap run fix-checkout-api-502s --var context=prod-us --var namespace=payments --var pod=payments-api-1 --var deployment=payments-api
Preflight  fix-checkout-api-502s
  1  Switch kube context           safe
     kubectx prod-us
  2  List pods in namespace           safe
     kubectl get pods -n payments
  5  Adjust deployment resource limits risky · prod
     kubectl set resources deploy/payments-api -n payments --limits=memory=1Gi
     undo kubectl rollout undo deploy/payments-api -n payments

  Preflight only. Add --execute to run (prototype safety default).

Models

A model rewords the draft; it never edits a command or lowers a risk label. Use Ollama locally, or any OpenAI-compatible API.

recap models set --provider ollama --model llama3.1:8b
recap models set --provider openai --model <model> --base-url <url>
recap models key set
recap models test
✓ llama3.1:8b answered in 7.547s

The API key goes into the macOS Keychain. Add --for-space to set a model for one space only.

Claude Code

Install the hooks once:

recap hooks install
  • PostToolUse captures the commands Claude Code runs into the session timeline.
  • PreToolUse blocks destructive prod commands when a verified recipe exists, so the agent uses the recipe instead.

Turn a recipe into a skill with recap skill. It writes ./.claude/skills/<id>/SKILL.md, or ~/.claude/skills/<id>/SKILL.md with --user. --dry-run shows what would be written.

$ recap skill fix-checkout-api-502s
✓ Wrote .claude/skills/fix-checkout-api-502s/SKILL.md
  Claude Code can now use it; it runs steps through recap run, so risk gates still apply.

Menu bar app

  • A native tray menu shows the recording, the session, how much was captured, and the current space.
  • The overlay (⌥⇧Space) starts a session or adds context, by typing or dictation.
  • Settings: launch at login, the CLI link, and a recordable shortcut.

Agents and scripts

Every prompt has a non-interactive path. Global flags work on every command:

  • --json for machine-readable output
  • --yes answers yes to prompts
  • --dry-run shows what would happen and changes nothing

Privacy

  • Secrets are masked locally before any model call or Git write.
  • Raw timelines stay on your Mac. Timelines, screenshots and transcripts never go into Git.
  • API keys live in the Keychain.
  • No telemetry, no hosted service, no audio recording.
  • recap never deletes on its own, and a model can never lower a risk label.

Command reference

CommandWhat it does
initMake this folder (or path) a recipe repo space; show next steps
spacesList spaces; add, use, remove
shell-initPrint shell integration, or --install it into your rc file
hooksManage Claude Code hooks
modelsModel for drafting: Ollama or any OpenAI-compatible API
startStart recording; this tab joins automatically
joinAttach this tab to the active (or named) session
leaveDetach this tab; recording continues elsewhere
statusShow the active session, attached tabs and sources
ctxAdd anything: a note, a link, a file (also reads stdin)
timelineEverything captured, merged by time (secrets masked)
stopReview, confirm the fix, draft the recipe, check for duplicates
findSearch recipes by meaning, with trust and risk
runPreflight, then run; asks for missing values; risky steps ask first
applyMerge a session's delta into recipes
publishCommit a session's recipe files per the space (PR, push, or none)
skillWrite a recipe as a Claude Code skill (--user, --dry-run)
pruneRemove archived sessions (only when you run it)
mcpServe recipes to AI agents over MCP (stdio): search, get, preflight, save, add context
versionPrint the version

Global flags: --dry-run, --json, --space (env RECAP_SPACE), --yes, -h, -v.
